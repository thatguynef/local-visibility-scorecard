# Examples

Every public example in this directory is **synthetic** or **sanitized**.

- [Acme Plumbing (synthetic)](acme-plumbing/README.md) — the golden fixture for V1.

A public example must not contain:

- a real business name, domain, phone number, or address;
- real customer data;
- a real geo-grid center or point coordinates;
- a real competitor set;
- a real DataForSEO task ID or account detail;
- a real screenshot.

The synthetic example is not a performance claim. It exists so a new contributor can run the full pipeline without credentials and compare their changes to a known result.
